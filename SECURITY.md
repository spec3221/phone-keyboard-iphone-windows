# Безопасность и приватность

## Что делает приложение с данными

- Приложение не подключается к Telegram, облаку, аналитике или стороннему серверу.
- Клавиатурные команды передаются напрямую с телефона на компьютер по локальной сети.
- При каждом запуске компьютер создаёт случайный токен доступа. Полная ссылка с токеном является секретом: не публикуйте её и не отправляйте посторонним.
- Приложение не записывает IP-адрес подключившегося телефона в журнал.
- Репозиторий не должен содержать токены, URL подключения, логи, виртуальное окружение или личные файлы.

## Важные ограничения

- Соединение использует HTTP/WebSocket без TLS. Используйте приложение только в доверенной частной Wi-Fi сети.
- Не запускайте сервер в общественной или гостевой сети.
- Не настраивайте переадресацию порта роутера и не выставляйте сервер в Интернет.
- Закрывайте программу на компьютере, когда закончите пользоваться клавиатурой.
- Любой человек, получивший полную ссылку с действующим токеном и имеющий сетевой доступ к компьютеру, потенциально может отправлять нажатия клавиш.

## Сообщения о проблемах

Перед публикацией отчёта удалите из него полные URL подключения, токены, IP-адреса и личные данные.
