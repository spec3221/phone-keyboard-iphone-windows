БЫСТРАЯ ЭКРАННАЯ КЛАВИАТУРА ДЛЯ iPHONE → WINDOWS 11

ОБНОВЛЕНИЕ:
1. Останови старую программу в чёрном окне сочетанием Ctrl+C.
2. Распакуй этот архив в НОВУЮ отдельную папку. Не смешивай со старой версией.
3. Запусти start_windows.bat.
4. Разреши Windows доступ в брандмауэре для частной сети.
5. Скопируй НОВУЮ полную ссылку из окна Windows.
6. На iPhone открой Safari вручную и введи полный адрес целиком.

ИСПОЛЬЗОВАНИЕ:
1. На ПК выбери мышью окно (например, Блокнот) и щёлкни в поле ввода.
2. На iPhone нажимай клавиши.
3. Ctrl / Shift / Alt / Win сначала подсвечиваются, затем нажми основную клавишу.
4. Статус показывает пинг в миллисекундах.

ЧТО УЛУЧШЕНО:
- Мгновенная реакция на касание (pointerdown).
- Нативный Windows SendInput и пакетная отправка нажатия/отпускания.
- Очередь команд с подтверждением и защитой от повторного ввода.
- TCP_NODELAY и обновление кэша Safari.
- На Windows больше не нужен pynput.

iPhone и ПК должны быть в одной Wi-Fi сети. Держи Safari открытым на переднем плане.
Не делись полной ссылкой с token: она даёт доступ к нажатию клавиш на ПК.
