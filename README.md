# Быстрая экранная клавиатура iPhone → Windows 11

Эта версия оптимизирована для быстрых касаний и устойчивой доставки клавиш по локальной Wi-Fi сети.

## Что улучшено

- **Меньше задержка на телефоне:** кнопки реагируют на `pointerdown`, не ждут запаздывающий синтетический `click` в Safari.
- **Нативный ввод Windows:** клавиши и сочетания отправляются через Windows `SendInput`; нажатие и отпускание клавиши передаются одним небольшим пакетом.
- **Более надёжные сочетания:** Ctrl / Shift / Alt / Win и основная клавиша собираются в одну последовательность, затем модификаторы отпускаются в обратном порядке.
- **Защита от потери команд:** у каждой команды есть уникальный ID, подтверждение от компьютера и повторная отправка при потере ответа. Повторы с тем же ID не печатают клавишу второй раз.
- **Меньше сетевой задержки:** на TCP включён `TCP_NODELAY`, WebSocket-компрессия выключена для коротких сообщений.
- **Пинг на экране:** статус показывает измеренный RTT в миллисекундах.
- **Старый кэш Safari обновляется:** файлы интерфейса получили новую версию, а service worker использует сетевой запрос для главной страницы, JS и CSS.
- **Меньше зависимостей:** на Windows используется встроенный API, поэтому `pynput` больше не нужен.

## Установка / обновление

1. Остановите старый сервер в его чёрном окне сочетанием `Ctrl+C`.
2. Распакуйте этот архив в **новую отдельную папку**. Не распаковывайте поверх старой версии.
3. Запустите `start_windows.bat`.
4. Если Windows спросит о брандмауэре, разрешите доступ для частной сети.
5. Возьмите новую полную ссылку из окна программы и откройте её вручную в Safari на iPhone.
6. Оставьте страницу открытой на переднем плане, пока используете клавиатуру.

iPhone и компьютер должны быть подключены к одной Wi-Fi сети. Программа должна оставаться запущенной на ПК.

## Использование

1. Сначала выберите мышью окно на компьютере (например, Блокнот) и щёлкните в поле ввода.
2. На iPhone нажимайте клавиши на экранной клавиатуре.
3. Для сочетания нажмите Ctrl, Shift, Alt или Win, затем нужную клавишу. Подсветка модификатора показывает, что он выбран.
4. В статусе «На связи» отображается примерный круговой пинг до компьютера.

## Важно

- На iPhone не сворачивайте Safari надолго: iOS может ограничивать сеть в фоне.
- При пинге 1–10 мс соединение обычно быстрое для локальной сети. Если значение высокое или скачет, причина чаще в Wi-Fi (слабый сигнал, перегруженная точка доступа или гостевая сеть), а не в клавиатуре.
- Не делитесь полной ссылкой с `token`: она даёт возможность нажимать клавиши на компьютере.
- Сочетание `Ctrl+Alt+Del` зарезервировано Windows для защищённого системного экрана и может быть недоступно для программной эмуляции.

## Приватность и безопасность

Приложение не использует Telegram, облако, аналитику или сторонние API: команды идут напрямую по локальной сети. При запуске генерируется случайный токен; не публикуйте полную ссылку `/?token=...`. Используйте только доверенную частную Wi-Fi сеть: соединение HTTP не шифруется, не открывайте порт в Интернет. Подробности — в [SECURITY.md](SECURITY.md).
